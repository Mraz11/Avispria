# Branding

The logo was designed by the project founder and coloured with an AI image tool.

- `logo-source.jpg`: the original picture, exactly as supplied (its navy X looked like a windmill).
- `logo.png`, `logo-dark.png`: the logo used by the program: a transparent cut-out of the original with
  the navy X redrawn as a drone seen from above (a body, four arms and four separate rotors). The tree and
  the mountains are untouched. In the dark one the navy parts are light, so it shows on a dark page.
  Smaller copies used by the window interface and the phone page are in `src/avispria/app/ui/assets/`
  and `field-page/img/`.
- Recreate every file (including the tab icon and the phone's home-screen icons) with
  `python scripts/make_branding.py`.
