# Branding

- `logo-source.jpg`: the original logo picture supplied by the project founder.
- `logo.png`, `logo-dark.png`: full-quality cut-outs (transparent background); the dark one has the
  navy parts made light so the X shows on a dark page. Smaller copies used by the window interface and
  the phone page are in `src/avispria/app/ui/assets/` and `field-page/img/`.
- Recreate all of them with `python scripts/make_branding.py`.
